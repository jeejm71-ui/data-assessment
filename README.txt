데이터 전처리 학습 교실 | 학생용 수행평가 안내

1. student-assessment.zip의 압축을 모두 풉니다.
2. 압축을 푼 student-distribution 폴더에서 index.html을 더블클릭합니다.
   HTML, CSS, JavaScript 파일은 같은 폴더에 둡니다. 인터넷이나 별도 설치 없이 열 수 있습니다.
3. 수행평가 메뉴에서 학번과 이름을 입력하고 선생님이 안내한 유형(A형 또는 B형)을 선택합니다.
4. 각 문항의 설명과 데이터 표를 확인하고 Python 코드 답안을 작성합니다.
   다시 열 때는 같은 브라우저에서 같은 위치의 index.html을 열고 같은 학번·이름·유형으로 시작하세요.
   브라우저 저장이 허용된 경우 이전에 작성한 답안을 이어서 작성할 수 있습니다.
5. 제출 파일 다운로드 버튼을 누르고 미작성 문항을 확인합니다.
   확인창에서 내려받기를 선택하면 학번_이름_A형.json 또는 학번_이름_B형.json 파일이 생성됩니다.
6. 브라우저 다운로드 목록에서 JSON 파일을 확인하고 선생님이 안내한 방법으로 직접 전달합니다.
